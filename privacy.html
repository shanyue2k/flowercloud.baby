隐私政策

我们坚守无日志原则，您的数字隐私安全是我们的核心承诺

在 Flower Cloud，我们坚信个人数字隐私是一项神圣的基本权利。本隐私政策旨在透明、详实地向您说明我们如何处理信息，以及我们如何从底层技术架构上杜绝日志收集，保护您的匿名性与信息安全。

🔒 核心原则：严格的【零日志记录】准则
Flower Cloud 庄重承诺：我们绝不记录、收集、监控、存储或转让用户的任何在线活动与网络流量数据日志。

🚫 我们绝不收集和保留的数据项

无论在任何情况下，Flower Cloud 的专线中转服务器及接入节点均经过纯内存无状态化运行配置，绝不会在磁盘上留存以下任何信息：

  • 不保留任何浏览历史与目标网址： 我们不知道您访问了哪些站点、使用了哪些网络工具、下载了什么文件或观看了什么视频。
  • 不保留任何 DNS 解析查询日志： 全网统一采用加密安全的私有 DNS 与 DoH 架构，您的域名查询请求均在内存中即时解析并即刻丢弃，不设任何回溯留存。
  • 不存储通信内容与传输数据包： 所有流经专线节点的用户流量均经过工业级端到端加密通道，传输过程为纯粹的管道转发，无法亦绝不进行深度数据包检测或数据还原。
  • 不记录用户源真实 IP 与连接时间戳： 我们不会将用户登录的客户端 IP 地址与特定节点线路建立任何关联映射日志。

📋 我们仅收集的最小化账户数据

为了向您提供基础的账号验证与技术服务，我们仅在极简原则下留存以下必要凭证：

  • 电子邮箱地址： 仅用于控制台登录鉴权、找回密码及重要系统变更通知。该数据经过强密码哈希加密，杜绝明文暴露。
  • 订阅到期时间与已用流量配额： 仅用于根据您购买的套餐方案计算当月剩余可用额度及服务生效周期。
  • 同时在线设备计数： 仅在连接建立瞬间于高速缓存中进行瞬时并发数校验，用于防止超出套餐限制，并在断开后自动清零释放，不产生历史持久化记录。

💳 支付隐私保护

Flower Cloud 不会在服务器上直接处理或存储您的银行卡号、信用卡安全码等敏感财务信息。所有支付流程均通过具备 PCI-DSS 安全认证的第三方合规结算渠道或去中心化加密货币网络完成，最大程度切断个人资金账户与网络活动的关联链条。

🛡️ 数据安全与绝对不对外共享

我们郑重承诺：

  • 我们绝不会向任何第三方数据经纪商、广告商或营销机构出售、出租或分享任何用户信息。
  • 即便面对任何非法的外部窥探，由于我们的系统架构从源头上采用了“无日志设计”，我们物理上也不存在可供提取或交接的历史行为日志。

🗑️ 您的权利：随时彻底注销与清空

用户享有对其个人账户信息的完全控制权。您可以随时在控制台提出注销申请。一旦确认注销，您的邮箱、订阅凭证及所有关联元数据将在 24 小时内从我们的主控数据库中被永久且不可逆地抹除。
